# Complete correction operands

Since 0.2.5 (cleanup-8), all automatic correction branches share a lexical connected-span check. The lexer groups runs of letters/numbers as atoms, keeps apostrophized words atomic, joins digit groups separated by whitespace, and connects atoms through punctuation or symbols by default. Unknown separators do not need entries in a denylist. A correction is refused if either boundary falls inside a connected component.

This applies to numeric values, times, repeated quantities, weekdays and the conservative name branch. For example, `Reference 123 : 456 actually make that 789.` stays literal, as do middle-dot, pipe, emoji, Unicode-format-symbol and nested connector variants. A replacement such as `Priya | 007` also stays whole rather than matching only its name prefix.

The grammar explicitly allows ordinary prose sentence delimiters, supported adjacent unary signs and percentages followed by prose. Terminal punctuation is not automatically part of an ID. Attached sentence punctuation followed by ordinary words can end a component; spaced punctuation between numeric or acronym-like components remains structural. Conservative preservation is intentional when a label or notation could be an ID. The lexer does not infer arbitrary semantic identifiers made entirely of prose words.

Final punctuation cleanup uses a literal-span view of the same token stream to protect structured references and internal whitespace. Ordinary wrappers, prose colons/dashes, words before currency amounts and word-only expressions remain available for capitalization; correction validation keeps the stricter connected-component boundaries. Regression tests require refused ID corrections to stay refused after formatting and on a second cleanup pass. Existing quoted spans, configured vocabulary and Exact mode remain protected. Standard scalar, time, weekday and name corrections continue to have positive regression fixtures. Speech recognition mistakes, name ambiguity and unrestricted semantic equivalence are not solved by lexical boundaries; Exact mode remains appropriate for verbatim text.

Tests include both operand sides, unknown punctuation/symbols, Unicode whitespace/format characters and joined emoji, all correction branches, repeated cleanup, optional cleanup fidelity, the packaged golden corpus and a named-clipboard/native text-control delivery fixture. Physical provider spelling and actual cross-app insertion remain separate manual checks.
